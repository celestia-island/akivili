# Contributing to akivili

The canonical contribution guide, merge policy, and review standards for the
celestia-island ecosystem live in the **plana** repository:

> https://github.com/celestia-island/plana — see `CONTRIBUTING.md` at the repo root.

Commit messages and PR titles must follow the ecosystem rules (gitmoji prefix,
English one-sentence summary ending with `.`, no `xxx:` colon prefixes), enforced
by the `celestia-devtools commit-msg-lint` CI workflow.

All work flows through feature branches and squashed PR merges; `master` is
protected. Development iterations happen on the `dev` branch.
